QR Code Generator

This small program asks you for some text or a website link, then saves a QR code image called my-qr-code.png. Scan the image with a phone to open the text or link.

  1. Install Node.js on your computer.
  2. Open a terminal in the project folder.
  3. Run npm install to get the QR code package.
  4. Run npm start, enter text or a link, and the image will be created in the folder.
