# QR Code Generator

A small Node.js program that turns text or a website link into a QR code image.

## Run it

1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install` once to install the QR code package.
4. Run `npm start`.
5. Enter text or a link when asked. The program saves `my-qr-code.png` in this folder.

The main program is in `index.js`.
